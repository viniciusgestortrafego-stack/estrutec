# Estrutec service thumbnails and footer contacts design

## Approved direction

Replace the six line icons in the “Tecnologia que enxerga” service grid with compact photographic thumbnails while preserving the existing card layout, copy hierarchy, and responsive two-column mobile grid.

## Image mapping

- Monitoramento 24 horas: operator monitoring security feeds.
- CFTV inteligente: monitoring center with camera wall.
- Alarmes inteligentes: connected home alarm and mobile interface.
- Controle de acesso e portaria remota: card-controlled business entrance.
- Aplicativo e acesso remoto: security camera mobile application.
- Projetos personalizados: security equipment and project plans.

Images use consistent aspect ratios, restrained saturation, rounded corners, descriptive alt text, and optimized WebP files.

## Footer

Add a “Contatos” block with the Guarulhos address, telephone link, and email link. On desktop it sits between the brand statement and the back-to-top link. On mobile it stacks vertically.

## Outputs

Update the responsive landing page, downloadable package, PDF export, and existing private Sites deployment.
